Cómo incluir Bootstrap en HTML

Bootstrap es una herramienta que permite diseñar páginas web de manera sencilla. Incluye estilos y componentes como botones, tarjetas y contenedores.

¿Cómo se incluye?

Para utilizar Bootstrap se agrega un enlace a su archivo CSS dentro de la etiqueta head del documento HTML.
