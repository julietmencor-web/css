Modelo de caja

El modelo de caja sirve para organizar los elementos de una página. Está formado por el contenido, el relleno, el borde y el margen.

Partes del modelo de caja

  • Contenido: es el texto o la imagen.
  • Padding: es el espacio entre el contenido y el borde.
  • Border: es el borde que rodea al elemento.
  • Margin: es el espacio que queda fuera del borde.
